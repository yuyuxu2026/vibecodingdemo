# 水果消消乐

**版本 0.0.4** · deepseek v4.1-flash 生成

## 更新记录

### v0.0.4

- 新增「玩法说明」：右上角 `?` 按钮打开说明弹层，分为基础玩法、特殊水果、闯关与星级三部分。
- 新增四种特殊水果，生成后留在棋盘上，再次参与消除时触发，可连锁爆破：
  - 横向火箭（↔）：横排 4 连 → 清除整行
  - 纵向火箭（↕）：竖排 4 连 → 清除整列
  - 炸弹（💥）：L / T 形同时消除 → 炸掉周围 3×3
  - 彩虹水果（✦）：5 个及以上直线相连 → 清除同种水果

### v0.0.3

- 本次新增的闯关玩法：
  - 10 个关卡：不同关卡拥有不同步数和分数目标，难度逐关提升
  - 1～3 星评分：最终得分达到对应门槛即获得相应星级；低于一星目标则挑战失败
  - 实时星级提示：顶部显示当前关卡、三个星级门槛，达到后星星会点亮
  - 关卡推进：一星即可解锁下一关，结果页提供“进入下一关”“再玩本关”
  - 选关地图：点击顶部“第 X 关”打开，可查看锁定状态、历史星级和步数，并重玩已解锁关卡
  - 进度保存：解锁进度、每关最佳星级和最高分会自动保存在浏览器本地，刷新后继续最高关卡
  - 结算界面：展示本局星级、得分、历史最佳、新纪录提示和星级动画
  - 全部通关：完成第 10 关后显示“全部通关”和收集到的总星数

### v0.0.2

- 新增消除音效：每次消除会播放气泡破裂、清脆琶音和轻微果汁质感音效，连击越高音调越高。
- 统一声音开关：右上角按钮由“音乐”改为“声音”，同时控制背景音乐和消除音效；关闭后全部静音，重新开启后恢复。

### v0.0.1

- 首个可玩版本：10×10 水果棋盘，点击相邻水果交换，横竖连成 3 个及以上即可消除。
- 有限步数、得分与连击加分，结束后结算本局得分。
- 由 deepseek v4.1-flash 生成，用时约 10 分钟。
